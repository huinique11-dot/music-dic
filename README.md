# music-dic

중학교 음악 수업용 웹앱 모음 (설치 없이 HTML 파일 하나로 실행)

| 파일 | 내용 |
| --- | --- |
| `festival.html` | **뮤직 페스티벌 랩** — 음악 취향 데이터 기반 축제 기획 3차시 프로젝트 (수행평가 40점) |
| `music_app.html` | 중학 기악 백과사전 — 악기별 운지법·코드·수준별 추천곡 |

## 뮤직 페스티벌 랩 (`festival.html`)

| 단계 | 화면 | 주요 기능 |
| --- | --- | --- |
| 사전 | 🛒 장바구니 | 5개 카테고리 태그 담기 + 최애 아티스트·곡·감정 서술(필수) |
| 사전 | 🪪 나 사용설명서 | 인스타 프로필형 카드 `[PROFILE]` `[MY SOUNDTRACK]` `[CONSUMPTION STYLE]`, 학생 원문 형광펜 강조, PNG 저장, 외부 AI용 프롬프트 복사 |
| 1차시 | 📝 보고서 | 서론·본론·결론 + 문장 틀, 음악 산업 트렌드 위젯, 반 보드, `[NEW DISCOVERY]` 댓글 |
| 2차시 | 🎪 축제 기획 | 학교/취향 맞춤형 선택, 라인업 포지션(헤드라이너~루키·첫 내한), 타임테이블, 셋리스트, 부스, 예산 게임(최대 700만 원 · 음향 ≤ 260만 원 · 조명 ≤ 40만 원), 필수 8대 항목 체크 |
| 3차시 | 🎧 청음 부스 | 셋리스트 썸네일 청음, 청음 QR(유튜브 재생목록 / 청음 웹페이지), A5 포스터 자동 생성·인쇄, 별점+건설적 피드백 |
| 평가 | ✅ 체크리스트 | 영역별 4요소 자동 판정 → 20/16/12/8/4점, 교사 인정/미인정 조정, 결과 복사 |

- 테마: 네오브루탈 / Y2K 글래스 / 다크 / 라이트, 화면: 데스크톱 16:9 ↔ 모바일 9:16 전환
- 데이터는 브라우저(localStorage)에 자동 저장됩니다. 서버가 없으므로 **반 보드 공유는 JSON 파일 내보내기 → 친구가 불러오기** 방식이며, 실제 수업에서는 패들렛과 병행하는 것을 권장합니다 ("패들렛용 텍스트 복사" 버튼 제공).
- "AI 분석"은 앱 안의 규칙 기반 엔진이 수행합니다(API 키 불필요). 더 풍부한 서술이 필요하면 "AI 심화 분석 프롬프트 복사"로 학교에서 허용한 AI 도구에 붙여넣으세요.
- "청음 웹페이지" QR은 앱이 웹에 게시되어 있어야(예: GitHub Pages) 휴대폰에서 열립니다. 파일로 열었을 때는 "유튜브 재생목록" QR을 사용하세요.
- 산업 트렌드 위젯은 정성적 설명만 담고 있습니다. 최신 통계는 KOCCA 음악산업백서에서 확인해 인용하도록 지도하세요.
