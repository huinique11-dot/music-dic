중학교 3학년 음악 · 음악 심리학 연구 7편을 바탕으로 **음악 취향을 분석 → 스스로 검증·수정 → 종이 활동지에 미니 연구보고서 → 돌려 읽기·댓글**까지 하는 수업 자료입니다. 2·3차시 축제 기획 / 청음 부스 / 40점 평가표도 같은 앱 안에 이어집니다.

## 선생님이 해야 할 설정

### 1. 앱을 인터넷 주소로 열기 (GitHub Pages) — 필수
학생이 집에서 과제를 하려면 앱이 웹 주소를 가져야 합니다.
1. 이 브랜치를 `main`에 합치기(병합)
2. GitHub 저장소 → **Settings → Pages → Build and deployment**에서 Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
3. 1~2분 뒤 주소: **https://huinique11-dot.github.io/music-dic/** → 이 주소를 학생에게 공유

### 2. 활동지 인쇄 (`worksheets.html` / `worksheets/` 폴더)
| 파일 | 내용 | 인쇄 |
| --- | --- | --- |
| `1_기본활동지_A5양면.pdf` | 앞: ① 취향 지도 색칠 ② 근거 데이터 ③ 검증표 / 뒤: ④⑤ 고른 활동지 ⑥ 새롭게 알게 된 나 ⑦ 친구 댓글 3칸 | 1인 1장, 양면 |

- A5 용지가 없으면 `…A4에2장씩` 파일을 쓰세요. A4 한 장에 같은 활동지가 2장 찍히므로 반으로 자르면 됩니다(기본 활동지는 양면 · 짧은 쪽 넘김).
- 인쇄 설정: 여백 없음, 배율 100%(실제 크기).
- 문구를 고치고 싶으면 `https://huinique11-dot.github.io/music-dic/worksheets.html`을 열고 '✏️ 글자 고치기'를 켠 뒤 직접 수정하고 인쇄하세요.

## 데이터 저장 방식 (서버 없음)
- 학생 기록은 **그 기기의 브라우저**에 반·번호·이름별로 따로 저장됩니다. 노트북 한 대를 여러 반이 함께 써도 섞이지 않습니다.
- 반·번호·이름을 똑같이 입력하면 기록이 이어집니다. 다 쓴 뒤에는 '↩︎ 나가기'를 누르게 지도해 주세요.
- 집(휴대폰)에서 한 과제는 **'📤 학교로 가져갈 링크 보내기'** → 카카오톡 나와의 채팅·클래스룸·이메일 등으로 보낸 뒤, 학교 노트북에서 그 링크를 열면 불러와집니다.
- 브라우저 기록 삭제·시크릿 모드에서는 저장되지 않습니다.

## 분석 방법과 주의점
- 취향 축은 Rentfrow & Gosling(2003)의 연구에서 시작해 5요인(MUSIC)으로 발전한 모델을 사용합니다. 장르 평가(75%) + 소리 취향 슬라이더(25%)로 계산하며 계산 방법은 앱에서 학생에게도 공개됩니다.
- 장르→취향 축 연결과 가중치는 수업용 단순화입니다. 연구 결과는 집단 수준의 경향이므로 앱은 결과를 '정답'이 아닌 '검증할 가설'로 제시합니다.
- 성격 검사는 포함하지 않습니다.
- 장르 도감 설명, 논문 요약 문장은 수업 전 교사 검토를 권장합니다.
